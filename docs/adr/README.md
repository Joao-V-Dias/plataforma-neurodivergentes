# Registro de Decisões de Arquitetura (ADRs)

Cada arquivo aqui documenta uma decisão de arquitetura significativa: o
contexto que a motivou, a decisão em si e as consequências (inclusive as
negativas/trade-offs). O objetivo é que alguém entrando no projeto meses
depois entenda *por que* o código é do jeito que é, sem precisar
reconstruir o raciocínio a partir do zero.

Formato: [Michael Nygard ADR](https://cognitect.com/blog/2011/11/15/documenting-architecture-decisions), simplificado.
